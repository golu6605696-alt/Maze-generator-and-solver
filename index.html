HOW ALGORITHMS WORK (DSA)

🌊 Breadth-First Search (BFS)

Expands evenly in all directions like ripples. Always finds the path with fewest steps.

🦔 Depth-First Search (DFS)

Explores deep along each branch before backtracking. Fast but not always optimal.

🧭 Dijkstra's Algorithm

Considers cell weights (mud/rubble). Always finds lowest stamina cost.

⚡ A* Search

Uses Manhattan distance heuristic to guide directly toward the exit.

🖐️ Wall Follower

Keeps right hand on the wall. Simple and memoryless.
